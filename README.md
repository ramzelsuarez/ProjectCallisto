\# Project Callisto



\*\*Project Callisto\*\* is an Unreal Engine 5.8 C++ project focused on learning and implementing scalable combat architecture using Unreal Engine's \*\*Gameplay Ability System (GAS)\*\*.



> \*\*Status:\*\* 🚧 In Development



\## Overview



The goal of Project Callisto is to build an action-RPG combat foundation using GAS while exploring modular and reusable gameplay systems in C++.



The project focuses on separating character state, abilities, attributes, effects, combat logic, and presentation into systems that can be extended as development progresses.



\## Tech Stack



\* \*\*Unreal Engine 5.8\*\*

\* \*\*C++\*\*

\* \*\*Gameplay Ability System (GAS)\*\*

\* Enhanced Input

\* Gameplay Tags

\* Gameplay Effects

\* Gameplay Events

\* Ability Tasks

\* Unreal Engine AI



\## Development Focus



Project Callisto is being developed around the following gameplay systems:



\* Ability System Component integration

\* Gameplay Abilities

\* Ability activation and Gameplay Tags

\* Attribute Sets

\* Gameplay Effects

\* Gameplay Events

\* Character health and death

\* Player and enemy combat

\* Enemy AI and target selection

\* Hit reactions and combat feedback

\* Gameplay Cues

\* Ability costs and cooldowns

\* Area-of-effect abilities and damage falloff



\## Project Goals



This project is intended to strengthen and demonstrate my understanding of:



\* Gameplay Ability System architecture

\* Ability-driven gameplay design

\* Data-driven combat systems

\* C++ and Blueprint integration

\* Reusable gameplay components

\* Character attributes and state management

\* Combat feedback and ability lifecycle management



\## Development Status



Project Callisto is currently under active development.



Features, source code, screenshots, and documentation will be updated as development progresses.
